## UX and accessibility

- New emptyViewsAndBackDismissDialogThenSearchThenReturnToMain test visits empty
  Main, Grouped and Archived, empty archived search, a populated paste dialog,
  and checks Back ordering: dialog without saving → search → Archived → Main.
  Production smoke additionally verifies root Back leaves Main.
- Labeled controls and semantic click actions are checked for Search, Paste link,
  Retry preview, Archive, Delete, Undo and the three selected navigation tabs.
  Button touch rectangles are measured with `SemanticsNode.touchBoundsInRoot`
  and must be at least 48 × 48 dp. Buttons provide alternatives to swipes;
  the instrumented test uses them to archive/delete and undo both operations.
- At system font scale 2.0, the search toolbar originally wrapped the app title
  into a second line ([before](WNT-222-large-before.png)). The title now uses one
  line with ellipsis. Decorative tab glyphs now have empty semantics, leaving
  meaningful text labels for navigation. Cached preview images remain decorative
  because the adjacent text already identifies the link.
- Empty, pending/offline, cached/enriched-offline and failed-preview states are
  exercised with the production app, not only injected test data. Loading has a
  progress indicator in FeedScreen/initial FeedState; a controlled slow-loading
  runtime screenshot is **not tested**.
- Undo is transient for the snackbar lifetime. Rotation/process death may dismiss
  it; soft deletion and persisted lifecycle state remain durable. Existing Room
  tests prove stale Undo cannot overwrite newer re-shares/actions or erase a
  later opening event. No permanent purge was introduced.

Official references used for the audit:
[Compose accessibility defaults](https://developer.android.com/develop/ui/compose/accessibility/api-defaults),
[SemanticsNode touch bounds](https://developer.android.com/reference/kotlin/androidx/compose/ui/semantics/SemanticsNode),
[Compose gesture testing](https://developer.android.com/develop/ui/compose/touch-input/pointer-input/understand-gestures).
